# Why do the residuals remain spatially autocorrelated?

## Data and diagnostics

All maps and semivariograms use *out-of-fold* RF errors from 1-km GroupKFold, never training-set fitted errors. Residual figures and exported 8NN neighbor weights are generated by `run_submission_tests.py`.

- `outputs/PPT_FIGURES/08_residual_diagnostics.png`: residual map, empirical semivariogram, Moran scatterplot and local Moran categories with BH-FDR 5% control.
- `outputs/tables/residual_semivariogram.csv`: 250-m separation bins up to 5 km; all pair counts listed.
- `outputs/tables/residual_distance_correlation.csv`: binned residual cross-product normalized by global residual variance (descriptive correlation proxy, not a formally fitted covariance model).
- `outputs/tables/residual_fold_summary.csv`: held-out fold mean error and RMSE, showing geography-dependent error shifts.

## Controlled hypotheses and interventions

We compared fixed-hyperparameter RF with projected-coordinate trends, 750-m target-free morphology neighborhood averages, their combination, and residual correction using *training-only inner spatial cross-fitted residuals*. Test LST and test residuals were never used in a correction.

| Model | RMSE °C | Residual Moran I | Permutation p |
|---|---:|---:|---:|
| RF | 0.891 | 0.439 | 0.001 |
| RF + coordinates | 0.820 | 0.383 | 0.001 |
| RF + morphology context | 0.903 | 0.435 | 0.001 |
| RF + context + coordinates | 0.842 | 0.375 | 0.001 |
| RF + inner-cross-fitted residual Gaussian kernel | 0.880 | 0.363 | 0.001 |
| RF + inner-cross-fitted residual KNN | 0.904 | 0.310 | 0.001 |

## Interpretation

Geographic location conveys predictive signal missing from the physical covariates; adding coordinates improves error but does not de-correlate residuals sufficiently. Neighborhood morphology averages alone are not useful under these settings. The local residual smoother reduces spatial dependence more strongly, but trades away predictive accuracy. This is a diagnostic association, **not proof that coordinates causally explain urban heating**.

Paired 1-km geographic-block bootstrap on fixed out-of-fold predictions gives RF-plus-coordinates minus RF RMSE of −0.071°C with 95% percentile interval [−0.113, −0.035]°C. It provides evidence for an error gain conditional on the fitted cross-validation predictions, but does not incorporate retraining variance.

There are also unmeasured potential variables: large roads, building height/density, microclimate, sensor and weather heterogeneity, adjacency to water and misalignment across OSM and satellite dates. Major-road distance and building heights were **not tested** because no validated corresponding layers exist in the current export. A neighborhood-mean LST derived using held-out targets would leak and was deliberately excluded.

## Remaining blocker

Moran I is still significantly positive for every tested model. A reviewer should continue to challenge the omitted spatial process. The most defensible next tests are geographically varying coefficients or spatial Gaussian-process residual models with an *inner* spatial selection scheme, and a genuinely independent acquisition to distinguish persistent geography from satellite artifacts. The current comparison is a fixed, preselected model screen rather than a hyperparameter-optimized claim.
