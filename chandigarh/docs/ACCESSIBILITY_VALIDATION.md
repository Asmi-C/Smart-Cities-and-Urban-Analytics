# Accessibility audit: new conceptual ZIP versus measurable data

The teammate ZIP contains only Markdown documents. It has **no** OSM POI coordinates, route graph, facility inventory, source snapshots, or independently labelled service datasets. The canonical `outputs/data/hex_results.gpkg` retains cached **network** nearest-facility distance for five service categories but does not retain nearest-facility *Euclidean* distance, source node locations or actual route geometries.

It is mathematically impossible to reconstruct correct Euclidean distance to an unknown POI from a network shortest-path length alone. Neither the circuity ratio (d_{\mathrm{network}}/d_{\mathrm{Euclidean}}) nor the number of service opportunities within 5/10/15 min can be derived from these caches. Consequently `outputs/tables/euclidean_vs_network_access.csv` records a **blocked/not-estimated** status, not simulated data or a fabricated comparison.

The verified *conditional-on-cache* analysis still shows that 2.162% of 2020-modelled residents reach all five categories within 15 min and nearest-eight access-score Moran I is 0.744 (p=.001). These numbers have not been externally validated against a contemporary OSM network or official facilities. The source code `src/newtown_smart_city_analysis.py` documents OSMnx nearest-node and multi-source Dijkstra with 4.8 km/h walking speed; its original OSM snapshot time is not included in the exported GeoPackage. WorldPop/GP/100m/pop 2020 is modelled data, and raster overlap accuracy/partial-cell choices cannot be recalculated without the source raster.

**Required source-level recovery:** independently export OSM features (IDs, types, timestamp, point/polygon geometry), full walking graph (node/edge geometry, length, access flags), then compute geodesic/projected straight-line and network shortest-path distances to the **same** facility set. Exclude not-verified or inaccessible facilities; document barrier and graph-connectivity effects. Avoid claiming systematic Euclidean misclassification until the paired test has been executed.
